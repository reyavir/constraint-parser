Inject IDs into source

      

        Add stable IDs (cv_0001, cv_0002, …) to every UI
        element in your source so CodeQL can locate them from constraints. This
        rewrites your HTML / JS files in place. If the target isn't a git repo,
        a .bak copy is written alongside every modified file.
